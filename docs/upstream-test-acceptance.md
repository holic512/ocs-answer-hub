# HTTP上游与单源测试验收

- 新增公网 HTTP / HTTPS 与有效自定义 TCP 端口支持；保留后台HTTPS、域名解析固定、私网及元数据限制，不接受非HTTP协议或URL内嵌账号密码。HTTPS仍校验证书，若需内网/回环由部署者做精确白名单。
- 来源行“测试”：读取当前保存配置，仅查指定源，即使来源未启用。
- 编辑页“测试当前配置”：使用当前未保存输入；若为已有来源，服务端恢复 ******** 的已存密钥。关闭测试回到原编辑表单，配置不会丢失或自动保存。
- 测试完整链路：配置 → DNS → TCP/TLS → HTTP状态 → JSON解析 → 业务状态 → 答案字段 → 题型/选项。正常未收录显示“接口已响应，本题未命中”，不声称答案链路全过。状态、未命中及异常不得统一当成通过。
- HTTP状态401/403鉴权失败、429限流、无效JSON、缺失响应路径、模型无效JSON、题干/选项不一致、网络超时分别给脱敏诊断；不返回原始错误、Authorization或原始响应。
- 测试不走本地和其他源，不改变来源启用/排序、题库、答案版本、provider_observations或query_events；不扣本服务OCS凭证额度，但可能消耗上游配额。
- 测试接口仅管理员且CSRF生效，限速和并发上限。
- 自动化：真实PostgreSQL集成；显式白名单的本地真实HTTP夹具覆盖200答案、200未命中、401、无效JSON、超时和302拒绝；浏览器覆盖草稿测试、保存来源测试、未启用测试和HTTP端口保存。夹具结果不冒充用户供应商实测。
