# 配置参考

## 运行配置

本地开发使用根目录 `.env`；镜像部署使用 `config/config.env`。`CONFIG_FILE` 指定外置文件后，文件值优先于同名环境变量，每次启动重新读取。外置文件每项一行，支持中文注释和引号，不接受未知字段、重复字段或跨行值；修改后重启。部署目录 `.env` 中的镜像、端口、`DATABASE_NETWORK` 属于 Compose 参数，不应写进应用配置文件。

```dotenv
DB_HOST=127.0.0.1
DB_PORT=5432
DB_NAME=answer_hub
DB_USER=answer_hub
DB_PASSWORD="填写数据库密码原文"
APP_ORIGIN=http://127.0.0.1:18771
STATE_DIR=./state
# 可选；必须是应用容器内可读取的绝对路径
# LOCAL_EMBEDDING_PATH=/app/storage/models/bge-small-zh-v1.5
```

| 字段 | 说明 |
| --- | --- |
| `DB_HOST` | 主机名或 IP，不含协议和端口；容器中的回环地址指向自身 |
| `DB_PORT` | 默认 `5432`；本项目本地数据库通常映射 `15432` |
| `DB_NAME` / `DB_USER` / `DB_PASSWORD` | 已存在的数据库、账号及密码原文，无需 URL 编码 |
| `APP_ORIGIN` | 地址栏中的协议、域名和端口，不带路径或末尾斜杠；开发前端默认 `http://127.0.0.1:5173` |
| `HOST` / `PORT` | 后端监听，默认 `127.0.0.1` / `18771` |
| `STATE_DIR` | 主密钥目录，本地默认 `./state`；镜像为 `/app/storage` |
| `LOCAL_EMBEDDING_PATH` | 固定本地模型目录，默认空；不配置时精确／安全模糊检索和普通 AI 查题仍可用，RAG、向量维护和种子生成不可用 |

数据库需要 PostgreSQL 17，以及已安装的 `vector`、`pg_trgm` 扩展。迁移账号需具备相应建表、改表权限；不能创建扩展时由数据库管理员预先创建。未知结构或迁移失败会阻止服务启动，见[数据库迁移](DATABASE_AND_VERSIONING.md)。

## 主密钥与配置升级

完成数据库迁移后，应用会在 `STATE_DIR` 中创建缺失的 `master.key`，内容为 64 位十六进制，新文件权限 `600`。后续启动读取原文件。AI 密钥加密保存在数据库，**数据库与原主密钥必须成套备份和恢复**。主密钥丢失后，生成新文件不能解密旧配置，只能恢复原密钥或重新填写 AI 凭据。

已有配置不自动覆盖。若更老版本曾手动配置主密钥，先将原值保存到状态目录的 `master.key`，确认与原数据库匹配，再移除已不支持的配置项；不要覆盖已有密钥。模型安装见[升级与向量运维](MULTIUSER_UPGRADE.md)。

## 系统设置

管理员在「系统设置」填写表单，保存后立即生效，存于数据库而非 `.env`。`GET/PUT /api/admin/settings` 使用以下完整对象：

| 字段 | 默认值 | 允许范围／含义 |
| --- | --- | --- |
| `registrationEnabled` | `true` | 是否开放用户名注册 |
| `registrationCredits` | `20` | 新注册及管理员新建账号赠分，整数 `0～1000000`；不追溯修改旧余额 |
| `tokenDailyDefault` | `2000` | 新凭证每日受理次数，整数 `1～100000` |
| `tokenRpmDefault` | `60` | 新凭证每分钟次数，整数 `1～600` |
| `tokenDailyMax` | `100000` | 本人凭证可设置的每日上限，整数 `1～100000` |
| `tokenRpmMax` | `600` | 本人凭证可设置的 RPM 上限，整数 `1～600` |

默认值不得超过对应上限。上限约束本人凭证的创建／编辑，不自动改写已存在的凭证。管理员通过管理接口代管凭证时，可在硬范围 `100000 / 600` 内设置高于系统上限的值。

## 账号、积分与凭证

系统为桌面浏览器使用的单系统，角色只有 `admin`、`user`。开放注册后，用户自行注册用户名和密码；忘记密码由管理员重置，没有邮箱找回。初始化及自行注册无需再次改密；管理员创建／重置的账号需先修改密码。禁用、删除或待改密账号不能使用 OCS 绕过限制。

积分归账号所有，次数和 RPM 归每个凭证。工作台必须选择本人的已有凭证并传入 `tokenId`；OCS 使用该凭证调用。一次已受理请求先冻结 1 积分，**成功返回本地或 AI 答案扣 1 分**；未命中、异常、繁忙释放冻结，不扣分。可用积分为 `balance - frozen`，不足 1 分拒绝受理。中断记录超过 5 分钟由任务 worker 释放，不自动重放查询。

凭证在受理时累计次数，受理后的未命中／异常不退还凭证次数。每日按 `Asia/Shanghai` 零点重置，RPM 为固定自然分钟窗口。输入、鉴权或限额失败不消耗次数。相同题目的并发请求可共用实际检索，但各调用分别记录和结算。

本人可新增、修改名称／额度／到期时间、撤销和删除凭证。完整凭证只在创建时返回一次，数据库仅保存哈希及前缀；撤销不可恢复。删除后仍保留查询记录中的凭证名称快照。管理员可在用户详情代管凭证、查看积分流水并按原因增减积分，调整后余额不能低于冻结额。

管理、AI 配置测试、导入导出、向量维护和种子生成不扣本系统查题积分或凭证次数；AI 测试及生成仍可能消耗供应商额度。

## AI 表单配置

系统仅支持本地题库与 AI。管理员在「AI 配置」使用表单，配置加密存入数据库；不会从 `.env` 或示例文件自动导入。可启停、排序和测试。API 的 `kind` 固定为 `ai`，外层字段为 `name`、`enabled`、`priority`（`1～9999`）、`timeout_ms`（`1000～45000`）及 `config`。

| `config` 字段 | 说明 |
| --- | --- |
| `baseUrl` | HTTP/HTTPS API 根、`/v1` 或完整 Chat Completions／Responses 路径；支持公网、局域网、自定义端口与容器主机名 |
| `apiKey` | 新建必填；编辑留空保留原密钥。读取接口仅返回空字符串和 `hasKey` |
| `model` | 供应商模型名称 |
| `maxTokens` | 整数 `64～16384`，默认 `1500`；是输出预算，不是正确率或费用承诺 |
| `apiFormat` | `auto`、`chat`、`responses`；`auto` 仅 URL 明确指向 Responses 时选择该协议，否则用 Chat，不自动发两遍请求 |
| `outputMode` | `prompt`：提示词约束；`json_object`：供应商 JSON 模式；`json_schema`：严格结构模式。选择供应商实际支持的模式，不静默降级 |
| `vision` | 是否向支持视觉的模型发送图片，默认 `false` |
| `enableThinking` | 可选布尔值；Chat 使用供应商兼容的 thinking 字段，Agnes 默认关闭，其余未设置时不附加；Responses 不应用该开关 |

旧 `jsonMode` 仅保留接口兼容：未传 `outputMode` 时，`true` 对应 `json_object`，否则 `prompt`。新表单使用 `outputMode`。无密钥参考见 [`examples/providers`](../examples/providers/)，不应写回真实凭据。

提示词版本为 `quiz-v2`，系统指令与题目 JSON 分离；单选／多选用选项 ID，判断题保留正确／错误，填空按空位数组输出，最终映射为原题答案。仅接收完整最终回答，拒绝推理片段、工具调用、截断和业务错误。完整回答的 JSON／选项映射错误在原超时内最多修复一次；不把超时、网络故障或截断当格式问题重复请求。结构通过不能证明答案正确。

表单测试可使用未保存或已禁用的配置，直接调用 AI，不经过本地题库、不保存配置、不写题库或正式查询记录。页面反馈请求编号和失败阶段；详见[日志](LOGGING.md)与[接口索引](API.md)。
